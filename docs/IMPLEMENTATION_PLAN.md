# Incremental Implementation Plan

## Phase 1 (Completed)
- Spring Boot backend foundation
- Schedule generation/listing REST APIs
- Architecture and API documentation
- React frontend scaffold

## Phase 2 (Completed)
- JWT authentication and RBAC
- Admin/Teacher/Student dashboard data contracts
- Manual override endpoint with re-validation

## Phase 3 (Completed)
- Real-time update channel (SSE)
- Notification module (in-app)
- Search/filter APIs and pagination

## Phase 4 (Completed)
- Export engine (CSV/PDF)
- Audit log persistence and query APIs
- Basic analytics endpoints (load distribution, room utilization)

## Phase 5 (In Progress)
- Automated tests:
  - unit tests for constraints and scoring
  - authentication service test
  - model overlap regression checks
- CI/CD and deployment hardening
